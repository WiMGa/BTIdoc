**Проблема:** Default 30 событий может превысить лимиты DC

**Решение:** Изменить default на 15
- 15 событий × 150 токенов ≈ 2,250 токенов (безопасно!)

**Изменено:**
```sql
-- Было:
CREATE FUNCTION log.get_recent_events(p_limit INTEGER DEFAULT 30)

-- Стало:
CREATE FUNCTION log.get_recent_events(p_limit INTEGER DEFAULT 15)
```
