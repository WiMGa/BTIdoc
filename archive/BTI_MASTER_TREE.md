#### ├── 🏆 Лучшие результаты сейчас
```sql
-- Топ-10 лучших соотношений Profit/DD
SELECT "sTaskId", "dProfitDDRatio", "kUsed", "iTPSL", "iShNo"
```

#### ├── 📈 Анализ последнего прогона
```sql
-- Итоги последнего FinalizeTasks
SELECT r.*,
       (SELECT COUNT(*) FROM "RunEquityPoints" WHERE "run_id" = r."run_id") as equity_points
FROM "RunSession" r ORDER BY "tm_started" DESC LIMIT 1;

-- Equity кривая последнего прогона
SELECT "seq", "tm", "equity" FROM "RunEquityPoints"
WHERE "run_id" = (SELECT "run_id" FROM "RunSession" ORDER BY "tm_started" DESC LIMIT 1)
ORDER BY "seq";
```

#### ├── 🔬 Статистика по параметрам
```sql
-- Эффективность k-NN значений
SELECT "kUsed", COUNT(*) as tests, AVG("dProfitDDRatio") as avg_ratio,
       MIN("dProfitDDRatio") as min_ratio, MAX("dProfitDDRatio") as max_ratio
FROM "Results" GROUP BY "kUsed" ORDER BY avg_ratio DESC;

-- Лучшие TPSL комбинации
SELECT "iTPSL", COUNT(*) as tests, AVG("dProfitDDRatio") as avg_ratio
FROM "Results" GROUP BY "iTPSL" ORDER BY avg_ratio DESC;
```

#### └── 🎯 Логика FinalizeTasks (как работает итоговый расчёт)
```
АЛГОРИТМ ФИНАЛИЗАЦИИ:
1. Для каждого eSh (вектора) найти лучший результат по dProfitDDRatio
2. Извлечь оптимальную TPSL: iTPSL = eBestParams.iTP * 4 + eBestParams.iSL
3. Создать единую временную сетку из всех equity всех векторов
4. Заполнить equity каждого вектора используя его лучшую TPSL
5. Суммировать все equity в общую кривую
6. Рассчитать Profit, MaxDrawdown, Profit/DD Ratio
```

```sql
       COUNT(CASE WHEN "dProfitDDRatio" > 0 THEN 1 END) as positive_results
```
