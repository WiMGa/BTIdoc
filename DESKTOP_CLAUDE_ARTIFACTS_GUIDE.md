# Как Desktop Claude делает выжимки (Artifacts)

## Что такое выжимка (Extract/Artifact)

Выжимка - это сохранённый артефакт в Desktop Claude, который содержит ключевую информацию из диалога в структурированном виде без снимков экрана и избыточного контекста.

## Зачем нужны выжимки

### Проблема
- Снимки экрана в Desktop Claude остаются в контексте диалога
- При каждом новом сообщении они продолжают потреблять токены
- Длинные диалоги со скриншотами быстро исчерпывают лимит токенов

### Решение
- Создать выжимку с ключевой информацией
- Начать новый диалог
- Загрузить артефакт в новый чат
- Продолжить работу без багажа старого контекста

## Как создать выжимку в Desktop Claude

### Метод 1: Через команду "Create artifact"

1. В диалоге попросите Claude создать артефакт:
   ```
   "Создай артефакт с выжимкой этого обсуждения"
   ```

2. Claude создаст структурированный документ с:
   - Ключевыми решениями
   - Важными выводами
   - Фрагментами кода (если есть)
   - Планами на будущее

3. Артефакт появится в боковой панели Desktop Claude

### Метод 2: Самостоятельное создание

Попросите Claude вывести структурированную информацию, затем:
1. Скопируйте текст
2. Сохраните как файл .md или .txt
3. Загрузите в новый диалог через прикрепление файла

## Что включать в выжимку

### Обязательно:
- **Контекст**: О чём был диалог
- **Ключевые решения**: Что решили, какой подход выбрали
- **Важные выводы**: Что узнали, что поняли
- **Код**: Критические фрагменты кода (не весь!)
- **План**: Что осталось сделать

### НЕ включать:
- Скриншоты (причина создания выжимки)
- Полную историю переписки
- Промежуточные неудачные попытки
- Избыточные детали

## Когда делать выжимки

### Триггеры:
1. **После больших обсуждений** с множеством скриншотов
2. **Перед сменой темы** в диалоге
3. **При приближении к лимиту токенов**
4. **После завершения логического этапа работы**
5. **Перед длительным перерывом** в работе

### Рекомендуемая частота:
- Каждые 50-100 сообщений с визуальным контентом
- После каждой сессии отладки со скриншотами
- В конце рабочего дня для сохранения прогресса

## Как использовать выжимку в новом диалоге

1. Начните новый чат в Desktop Claude
2. Прикрепите файл с выжимкой ИЛИ скопируйте артефакт
3. Напишите: "Продолжаем работу. Вот контекст из предыдущего диалога."
4. Claude восстановит понимание без токен-тяжёлого контекста

## Пример структуры выжимки

```markdown
# Выжимка: Работа над BTI проектом (2025-10-07)

## Контекст
Работали над исправлением look-ahead bias в BTIwork.

## Ключевые решения
1. Добавили проверку времени pEnd относительно eSh.pCreated
2. Если pEnd позже создания шаблона - клипаем на eSh.pCreated.d
3. Это предотвращает использование будущих данных

## Код
```csharp
if (eV.lResult[iUpDown].pEnd.tm <= eSh.pCreated.tm)
{
    adPEnd[idx] = eV.lResult[iUpDown].pEnd.d;
}
else
{
    adPEnd[idx] = eSh.pCreated.d;
}
```

## Что осталось
1. Запустить BTIwork на реальных данных
2. Загрузить результаты в PostgreSQL
3. Протестировать на синтетических данных
```

## Интеграция с БЗ (База Знаний)

После создания выжимки рекомендуется:
1. Важные выжимки сохранять в PostgreSQL БЗ
2. Использовать logging.search_messages() для поиска
3. Ссылаться на выжимки в заданиях через tasks

## Поиск выжимок в БЗ

```sql
SELECT * FROM logging.search_messages('выжимка BTI', 10)
```
